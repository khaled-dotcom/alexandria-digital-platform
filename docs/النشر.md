# نشر المنصة على استضافة حقيقية

## ليه GitHub Pages مايشتغلش

الـ Pages بيستضيف **ملفات ستاتيك بس** (HTML/CSS/JS). المنصة دي:

- سيرفر **Node.js + Express** بيرد على `/api/*`
- قاعدة **SQLite** على القرص
- **جلسات** بكوكيز موقّعة
- **رفع صور** بيتكتب على القرص
- **محرك SLA** بيشتغل كل ٥ دقايق في الخلفية

مفيش حاجة من دول ممكن تشتغل على Pages. لازم استضافة بتشغّل Node.

---

## المتطلب الأساسي: قرص دائم

القاعدة والصور بيتكتبوا على القرص. أي استضافة بقرص **مؤقت** (ephemeral) هتمسح
كل البيانات مع كل نشر أو إعادة تشغيل. المسارات دي قابلة للضبط:

| المتغيّر | الافتراضي | للنشر |
|---|---|---|
| `DB_PATH` | `data/app.db` | `/data/db/app.db` |
| `UPLOAD_DIR` | `uploads/` | `/data/uploads` |

## المقارنة

| الاستضافة | قرص دائم | التكلفة | الملاحظات |
|---|---|---|---|
| **Fly.io** | ✅ volumes | فيه سماح مجاني | الأنسب — `fly.toml` جاهز في الريبو |

| GitHub Pages | ❌ | مجاني | **مايشغّلش المشروع أصلاً** |

## Fly.io (موصى به)

```bash
# ١. ثبّت الأداة وسجّل دخول
#    ويندوز: iwr https://fly.io/install.ps1 -useb | iex
fly auth login

# ٢. اعمل التطبيق من غير نشر (عشان نظبّط الأسرار الأول)
fly launch --no-deploy

# ٣. اعمل القرص الدائم
fly volumes create alx_data --size 1 --region cdg

# ٤. ظبّط الأسرار
fly secrets set SESSION_SECRET="$(node -e "console.log(require('crypto').randomBytes(32).toString('hex'))")"
fly secrets set ANTHROPIC_API_KEY="sk-ant-..."      # اختياري — للتصنيف الآلي

# ٥. انشر
fly deploy

# ٦. اعمل أول حساب موظف (مرة واحدة بس)
fly ssh console -C "node scripts/set-password.js"
```

بعدها الموقع على `https://<اسم-التطبيق>.fly.dev`.

> **مهم:** `fly launch` ممكن يكتب فوق `fly.toml`. لو عمل كده، رجّع منه قسم
> `[[mounts]]` وقسم `[env]` — من غيرهم البيانات مش هتتحفظ.

## Railway

1. من [railway.app](https://railway.app) اعمل **New Project → Deploy from GitHub repo**.
2. Railway هيكتشف الـ `Dockerfile` لوحده.
3. من **Variables** حطّ:
   ```
   SESSION_SECRET = <٣٢ حرف عشوائي على الأقل>
   NODE_ENV       = production
   TRUST_PROXY    = 1
   DB_PATH        = /data/db/app.db
   UPLOAD_DIR     = /data/uploads
   ```
4. من **Settings → Volumes** ركّب volume على `/data`.
5. بعد أول نشر، من الـ shell: `node scripts/set-password.js`.

## VPS بـ Docker

الريبو فيه `docker-compose.yml` جاهز بـ volumes ونسخ احتياطي يومي:

```bash
git clone https://github.com/khaled-dotcom/alexandria-digital-platform.git
cd alexandria-digital-platform
cp .env.example .env
# ظبّط SESSION_SECRET في .env
docker compose up -d
docker compose exec app npm run set-password
```

حطّ **Caddy** أو **nginx** قدامه للـ HTTPS، وخلي `TRUST_PROXY=1`.

## قبل ما تنشر — تشيك ليست

- [ ] `SESSION_SECRET` عشوائي و٣٢ حرف على الأقل (**مش** اللي في `.env.example`)
- [ ] `NODE_ENV=production`
- [ ] `TRUST_PROXY=1` لو وراك بروكسي — من غيره حد الطلبات بيحسب كل الزوار IP واحد
- [ ] قرص دائم مركّب و`DB_PATH`/`UPLOAD_DIR` مأشّرين عليه
- [ ] **غيّرت باسوردات حسابات الـ seed** — `alexandria2026` معروف لأي حد شاف الريبو
- [ ] `npm run backup` متجدول يوميًا
- [ ] `/healthz` بيرجّع `200` و`pending: 0`

> **حسابات الـ seed للعرض بس.** لو نشرت من غير ما تغيّرها، أي حد يقدر يدخل
> بصلاحيات كاملة. للنشر الحقيقي: اعمل حسابات جديدة من `/admin` وأوقف القديمة.
